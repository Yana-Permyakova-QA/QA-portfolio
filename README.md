Учебный проект по ручному тестированию на тренировочном сайте https://automationexercise.com/.

**Период работы над проектом:** 27.10.2026–29.10.2026

**Окружение:** Яндекс Браузер 26.10.0.1854 (64-bit), Windows 11 Pro 25H2

Смоук-тест регистрации и входа, первый шаг регистрации (поля “Name” и “Email Address”), поля форм “Enter Account Information” и “Address Information”, вёрстка на разных размерах экрана (DevTools).
