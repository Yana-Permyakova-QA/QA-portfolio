# BUG-002: Обязательные поля формы регистрации принимают значения из одних пробелов, аккаунт создаётся с пустыми данными

**Серьезность**:  Minor

**Приоритет**: Low

**Воспроизводимость:** (1 раз из 1)

**Окружение**: Яндекс Браузер 26.10.0.1854 (64-bit), Windows 11 Pro 25H2

**Предусловие**:

Пользователь не авторизован, e-mail не зарегистрирован.

**Описание**

Форма не проверяет содержимое обязательных полей, значения из одних пробелов принимаются, аккаунт создаётся. 

**Шаги воспроизведения**:

1.Открыть https://automationexercise.com/login

2.В блоке  "New User Signup!" ввести валидные “Name” и “Email Address”, нажать “Signup”

3.В формах “Enter Account Information” и “Address Information” ввести по одному пробелу в "Password", "First name", "Last name", "Address", "State", "City", "Zipcode", "Mobile Number" (поле "Company" не заполнять)

4.Нажать “Create Account”

5.В приветственном окне нажать «Continue» 


**Фактический результат**:

Показано приветствующее сообщение “Account Created!”, регистрация завершена.

**Ожидаемый результат**:

Показана ошибка, регистрация не продолжается, обязательное поле не может состоять из одних пробелов.

**Связный дефект:** [BUG-001](BUG-001.md) (пробелы в поле “Name” на первом шаге регистрации).


**Примечание**: 
Требования к полям на сайте нет, ожидания основаны на общепринятой практике, аналогичный результат при вводе двух и трех пробелов.
